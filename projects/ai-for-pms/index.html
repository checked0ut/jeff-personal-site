AI for PMs, in practice

What I've been figuring out about applied AI for PM work, shared as I go.

The itch

Most AI-for-PM content is theoretical, written by people who don't ship product. I wanted to write the version that's grounded in actually using these tools every day on real PM work.

What's out there so far

A month with Claude Code as a PM. A writeup on what happened when I stopped writing my own one-pagers, discoveries, and epics, and started using Claude Code to assist all of them. The headline finding wasn't what I expected. The value isn't in Claude Code as a writing tool. It's in Claude Code as a thinking partner that prompts me with the right questions, so the answers I produce are sharper than the ones I'd have arrived at alone. Reach for AI to be prompted, not to be answered.

An in-person session for the product and engineering teams. One hour, co-run with an engineer. The audience walked away understanding the power of MCP connections into Confluence and Jira, a personal audit skill that lets you audit your own Jira, what it looks like to automate a weekly sync meeting, and what it looks like to automate data analysis. The session wasn't a demo of impressive tricks. It was a working set of patterns people could go back to their desks and apply.
