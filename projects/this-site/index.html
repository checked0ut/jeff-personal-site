This site

Built with Claude Code, in patches.

The itch

The thesis on the homepage isn't worth much without evidence. The evidence existed but lived in a dozen disconnected places. The site is the home that pulls it together.

How it got built

In thirty-minute sprints, mostly. With a seven-month-old at home, there is no clean weekend to sit down and build something end to end. There are patches of evenings, the half hour before bedtime, the gap between a nap starting and a nap ending. So the workflow had to match the time available, not the other way around.

What I learned about Claude Code

Most AI coding content is about one-shot artifacts; a site you maintain is a different problem. The first thing to get right was thinking through what content is actually meaningful to share, and then how to display it so a reader gets the point quickly. A clear CLAUDE.md capturing my preferences was the unlock that let each short session pick up where the last one left off.

What's next

The site updates as the work changes. If the homepage looks different in six months, that's the point.
